# Aokana

「她说，只要你能保持乐观的心态，你就会发现这世上有着数不尽的开心事」

「她还说，如果以前的你非常内向，那今后一定会有成倍的快乐等着你」

「越是新手越应该多比赛。可以让她们早点体会一下只有在比赛中才能知道的东西」

「反正集训已经定了，就算觉得不可能做到，也必须抓住机会尝试一次」

「而且设个死线你们练起来也更有干劲吧？要是光想着慢慢练基础，练多久都不会认真起来的」

「要是认真不起来，基础也是不可能打牢的」

「我知道了，教练！请尽情折磨我的身体吧！」

「你不光是一个教练。不要忘了依靠我们。不要不信任我们。……这样的话，我们也会回应你的」

「飞行技术不好，就应该去训练！同样的，想和她搞好关系，就应该努力去搞好关系」

「总觉得现在的学长好像没有什么感兴趣的事，或者说没有什么能让你产生热情的事……」

「因为他们很可怕，所以我也能让自己鼓起勇气，竭尽全力。与可怕的对手较量是很快乐的」

「她说，我应该去见识更多的东西。不然，我很快就会碰到自己的极限」

「所以，我想改变自己的日常生活，哪怕只有一点点也好」

「所以，既然之前难得有了和大家混熟的机会，我就很想和久奈滨的同学们多说说话，一起多训练几次」

「哎呀，虽然输的很彻底，但我感觉并没有表面上看起来那么彻底~」

「要是势头不对，我会立刻跟你说的。你就尽情发挥吧。畏首畏尾才是最不能原谅的」

「仓科部不仅是空竞，还是你的同伴同学。要是不开心，就算不上社团活动了」

「你难道以为我是什么完美超人吗？」

「我这个人，不管对谁，都会用比较恭敬的语气说话，这就容易跟别人产生隔阂」

「老师正在教导他们——有些景色，如果你站在那样的高度，永远也无法看到」

「我也是！能和最喜欢的你，在最热爱的天空中一起飞翔——」
