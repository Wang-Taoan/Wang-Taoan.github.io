# 天气之子

## 摘录

「东京好可怕」

「不过，我不想回去」

「每天都可以用拼命二字来形容，但我还是第一次这样被人依赖」

「帆高呢 为什么要离家出走」——「因为感觉很闷，无论是那个地方还是父母」

「人的内心真是神奇，像是只要早上看到窗外的晴天，就能精神百倍；只要天空一片蓝色，就能感叹活着真好」

「什么嘛，我才是年龄最大的」

「别管我了啊！为什么要挡在我前面啊 」

「あんた何も知らないで知るないフリして」——「你明明什么都不知道却假装知道」

「究竟 该怎样形容呢？」

「君を大丈夫にしたいじゃない・君にとっての「大丈夫」になるために」——「我不希望你成为那个可以被任何人轻易对付的人；我希望你能成为一个无论何时何地都能保护自己的人。」

「对了，写成报告或许能赚到钱」「你越来越像小圭了，要变成一个无趣的大人了」

## 想法

1.青春懵懂的爱

2.对未知世界的好奇和向往；被残酷社会的打击

3.一个人在陌生社会里逼仄地生活：一个人躲在角落、一个人坐公交车、

4.成年？成人？成为大人？ 成为自己？四者

成年是身体上的成熟；成人（动词：成为人）是心智上的成熟；成为大人是被社会限制、是利益的驱使、是责任的承担；成为自己是保持赤子之心，真正意识到自己喜欢什么、想要什么的那一刻就成为了自己。

成为大人是迫不得已，但仍然希望能在空闲的时间里，做个天真无邪的少年，成为自己。
