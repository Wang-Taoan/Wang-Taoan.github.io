# 随笔记 | 2508

「越该做的事，越是急不得」

人的成长是摸石头过河，是实践-总结-实践中反复进行的

总是在选择中犹豫，本质是想做一劳永逸的事，不想失败。其实事情都是在尝试后失败，失败后继续尝试，最终才有可能找到合适的选择，如果想明白了这些，我想自然就不会面对选择犹豫不决了。

你喜欢的东西是最贵重的。 你喜欢的东西是最便宜的。

我对世界的观点是，认命，大多东西都是天生使然，不是能通过努力改变的；适当的努力，在既定的范围下，尽力能通过努力稍微调整一些，就已经很好了。

意义的定义是我觉得有意义。

我觉得事物的发展都是从一个极端走到另一个极端，再走回到原来的极端或者走向平衡。

在自己的规则下想怎么做都可以，在别人的规则下能怎么做都是顺其自然。

如果要牺牲个人的幸福去养小孩的话，还是把幸福留给自己吧

沉没成本不参与重大决策->果断放下过去的损失，才能避免未来更大的损失，去迎接更好的机会。

有意思>有意义
